# Dataset Provenance, Attribution, and Setup Guide

## 📌 Dataset Overview

- **Dataset Identifier**: FER-2013 (Facial Expression Recognition 2013)
- **Primary Source / Kaggle Reference**: [msambare/fer2013 on Kaggle](https://www.kaggle.com/datasets/msambare/fer2013)
- **Original Academic Provenance**: Challenges in Machine Learning (ICML 2013 Workshop on Representation Learning)
- **Original Authors / Collectors**: Pierre-Luc Carrier and Aaron Courville (Universite de Montreal)
- **License**: The original FER-2013 dataset was released for the Kaggle ICML 2013 competition for open research and educational benchmarking. Commercial redistribution of the raw imagery is restricted. The repository excludes all raw data and weights in `.gitignore` to comply with licensing and copyright terms.

---

## 🏷️ Canonical Emotion Taxonomy

All pipeline components, preprocessing scripts, model heads, and API schemas use the standardized 7-class taxonomy in this exact order:

| Class Index | Emotion Name | FER2013 Folder Name / Label | Description |
| :---: | :---: | :---: | :--- |
| `0` | **Angry** | `angry` | Lowered brow, tightened lips |
| `1` | **Disgust** | `disgust` | Wrinkled nose, raised upper lip |
| `2` | **Fear** | `fear` | Raised brows, widened eyes |
| `3` | **Happy** | `happy` | Upturned corners of mouth, crinkled eyes |
| `4` | **Sad** | `sad` | Drooped eyelids, turned-down corners of mouth |
| `5` | **Surprise** | `surprise` | Dropped jaw, widened eyes and raised brows |
| `6` | **Neutral** | `neutral` | Relaxed baseline facial expression |

## 📥 Acquisition & Download Instructions (Windows PowerShell)

### Option A: Authenticated Kaggle CLI (Recommended)

1. Ensure your Kaggle API token `kaggle.json` is located in `~/.kaggle/kaggle.json` (e.g. `C:\Users\<username>\.kaggle\kaggle.json`).
2. Run the following PowerShell commands from the repository root (`D:\FaceRecognition`):

```powershell
# Create target directory
New-Item -ItemType Directory -Force -Path "data/raw"

# Download the dataset archive
kaggle datasets download -d msambare/fer2013 -p data/raw

# Extract archive
Expand-Archive -Path "data/raw/fer2013.zip" -DestinationPath "data/raw" -Force

# Optional: clean up zip
Remove-Item "data/raw/fer2013.zip"
```

### Option B: Manual Web Download

1. Navigate to: `https://www.kaggle.com/datasets/msambare/fer2013`
2. Log into your Kaggle account and click **Download (96 MB)**.
3. Move the downloaded `fer2013.zip` or archive to `data/raw/`.
4. Extract the contents so that `data/raw/train` and `data/raw/test` (or `fer2013.csv`) are placed directly into `data/raw/`.

## ⚙️ Running Data Preparation & Integrity Check

Once the dataset is extracted into `data/raw/`, execute:

```powershell
python -m scripts.prepare_data --raw-dir data/raw --output-dir data/processed --val-split 0.15
```

This will:
1. Scan for unreadable or corrupted image files.
2. Verify class label consistency against the 7 canonical classes.
3. Compute class balance distributions across train, validation, and test splits.
4. Save structured metadata (`dataset_metadata.json`) into `data/processed/` and `artifacts/reports/`.
